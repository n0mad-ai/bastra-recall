## Supersession (#1229, #644, #600)

The targeted-old-value reproduction initially returned eight filler notes before
`new:0.074 old:0.073`; without the supersession edge, `old:170.089` ranked first.
After this change: `new:170.090 old:170.089`, then the fillers. The second query
likewise changes from both versions below fillers to `new:119.397 old:119.396`.

Successors inherit a retrieved predecessor's score plus one precision unit after
fusion/lifecycle multipliers, before candidate-pool emission and top-k. Traversal
propagates oldest to newest. Predecessor and unrelated scores remain unchanged;
missing, filtered and cyclic successors do not affect the score. Direct and hop
lanes stay separate, so a hop successor cannot displace a direct predecessor.
The batch merge moves the successor forward while retaining actual subquery scores.

The downstream `min_score` floor and bands see the promoted ranking score: a
retrieved successor can now cross a floor/band with its predecessor. This is an
intentional consequence of ranking current state above a strong old-value match;
no absent/filtered candidate is retrieved and no floor constants change. Batch
scores remain the selected single-query scores, as before, so batch rank need
not be descending by score. Batch already merges a global union rather than
retaining each subquery's hop groups (one ID can be direct in one query and a
hop in another); that contract is unchanged. This is no historical/as-of
answer implementation.

## Other reproduced findings

- Claim stress: 12 processes x 400 acquisitions. Before: 19 raw EINVAL errors,
  0 overlapping holders. After: 0 raw errors, 0 overlapping holders. Contention
  still returns write conflicts. Deterministic fault injection verifies one
  retry and conflict after the second EINVAL.
- Graph freshness: rename, old-mtime replacement and changed size with preserved
  mtime were falsely fresh. The sorted path/mtime/size signature detects all;
  missing signatures require one rebuild. A real stand-in extractor editing
  a source late in the build verifies the successful manifest's start stamp.
  A deterministic event during a delayed fresh scan verifies a promised build.
  This is metadata detection, not content hashing: same path/size/mtime with
  different bytes is outside its guarantee.
- Linux watches: original 9,000-package venv reproduction allocated 8,192 watches,
  8,179 inside venv; after: 3 source-directory watches, 0 in ignored trees.
  A deterministic 8,192-watch test verifies that removing one watched directory
  permits a new registration. No timed ENOSPC retries were added; a kernel
  limit with no observable handle removal can still require restart/re-enable.
- Resumed-session cache: two parent PIDs using one session ID shared width/tty
  and Claude feed PID before. They now resolve independently. All current cache
  fields depend on process ancestry/terminal, so there is no session-only data
  to share. Same-parent independent ticks still reuse the cache; a new wrapper
  parent pays a fresh parent-chain lookup.
- Old Git: an injected unsupported-option failure lost working-tree counts.
  One retry without `--ahead-behind` preserves branch, dirty counts and available
  tracking counts. The normal path remains one fresh Git status query per tick.
- Cyrillic word forms: fixed seed 42, 1,500 trigger tokens x 4,000 context tokens,
  five sequential runs after the final full test suite, median 324 ms before / 210 ms
  after (about 35% lower). Bounded string-based normalization reuse avoids a
  mutable-Set cache and repeated normalization in the pair matcher. Accepted
  affix families are unchanged. English list/listen and serve/server remain
  known accepted false-pair limits, per the audit's explicit scope.
- Legacy bridge IDs: both ß and İ produced a second file after normalization;
  archive IDs could be revived. Minting now indexes canonical term identities
  once per language/pass, keeps existing IDs/filenames and their evidence,
  earliest first_seen and demotion, and respects canonical archive matches.
  No automatic bulk migration or deletion of old files runs.
